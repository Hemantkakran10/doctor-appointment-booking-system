Core Project Highlights

• Real-time Doctor Appointment Scheduling across 50+ Verified Delhi/NCR Specialists
• Clinical AI Symptom Checker powered by Google Gemini 1.5 Flash for instant triage

Live App: frontend-ten-pearl-81.vercel.app
Context & Motivation

The Healthcare Access Dilemma in India

🏥 Unpredictable Clinic Queues

Patients spend 2-4 hours in crowded waiting rooms with no live transparency on doctor delays or slot availability.

⚠️ Lack of Pre-Consult Triage

Patients cannot self-assess symptom severity before traveling, causing overcrowding in emergency departments.

📝 Handwritten Prescription Errors

Messy handwriting on paper prescription slips leads to incorrect medicine intake, wrong dosages, and missed courses.

🔌 Fragmented Healthcare Portals

Booking, medical history, and clinical records exist in silos with no unified digital interface for patients and doctors.

Technical Architecture

3-Tier Cloud Architecture & Data Pipeline

Client Tier (Vercel CDN)

  • React 18 + Vite: Sub-second HMR and lightweight bundle size
  • Tailwind CSS: Adaptive mobile-first responsive layout
  • Context API: Global auth, language, and alert states
  • Bilingual Engine: English & Hindi full-site localization
  • Offline Fallbacks: Seamless client-side doctor caching

Serverless API Tier (Node.js)

  • Express.js: Modular REST controller routes
  • Vercel Edge Functions: Auto-scaling serverless lambda
  • JWT Security: 30-day cryptographically signed tokens
  • Non-Buffering DB Mode: Fail-fast under 300ms latency
  • Role-Based Access: Patient, Doctor, and Admin routes

Data & AI Cloud Services

  • MongoDB Atlas: NoSQL cloud store for users and appointments
  • Google Gemini 1.5 Flash: Multimodal visual reasoning and medical triage
  • Gmail SMTP Relay: TLS authenticated 6-digit OTP delivery
  • Unsplash CDN: High-resolution verified medical portraits

Artificial Intelligence

Deep Dive: Clinical AI Symptom Checker

Clinical Triage Workflow

  • Patient Input: Age, gender, duration, severity, and description.
  • Prompt Guardrails: Enforces JSON schema output, preventing conversational hallucination and ensuring medical safety disclaimers.
  • Urgency Triaging:
    • 🟢 Low: Routine care & lifestyle advice.
    • 🟡 Moderate: In-person consult within 48h.
    • 🔴 High: Immediate Emergency Room alert.
  • Specialist Auto-Routing: Recommends matching doctors (e.g. Cardiologist) with 1-click booking button.

Sample Clinical Triage Output

Computer Vision AI

Deep Dive: Vision Prescription OCR

Multimodal Vision Pipeline

  • Multi-Format Ingestion: Accepts camera uploads or JPEG/PNG files up to 15MB.
  • Gemini 1.5 Flash Vision: Transcribes messy clinical cursive and medical shorthand (e.g., '1-0-1' or 'TDS').
  • Entity Normalization: Maps brand names to generics and calculates exact daily schedules.
  • Patient Guidance: Highlights warnings like 'Take after food' or 'Do not stop antibiotic early'.

Security & Reliability

Zero-Downtime Security & Data Integrity

🔐 Live Email OTP Verification

Authentic 6-digit verification code dispatched directly to user inboxes via Gmail SMTP with zero on-screen leakage and 10-minute automated expiry.

⚡ Fail-Fast Non-Buffering Handlers

Disabled Mongoose command buffering for instantaneous under-300ms serverless response, with automatic cold-start retry mechanisms.

🛡️ Role-Based Access Control (RBAC)

Cryptographically signed JWT bearer tokens with 30-day life, bcrypt password hashing, and isolated patient, doctor, and admin portals.

📅 Atomic Anti-Collision Booking

Real-time slot concurrency locks preventing double bookings on doctor schedules, with instant 1-click patient cancellations and slot replenishment.
